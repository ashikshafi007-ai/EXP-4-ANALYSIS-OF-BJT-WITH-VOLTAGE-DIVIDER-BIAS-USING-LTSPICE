# EXP-4-ANALYSIS-OF-BJT-WITH-VOLTAGE-DIVIDER-BIAS-USING-LTSPICE
Aim: To design and simulate the BJT with voltage divider bias using LTspice.
Components Required: PC with LTspice software.
Procedure:
Open LTspice software.
Go to LTspice and open the File menu.
Create a new project.
Create the circuit and enter the required SPICE program/netlist.
Save the file with .cir extension.
Simulate and run the program and observe the output.
OBSERVATION:
